# Voxy Website 🌐

Site oficial de apresentação, download e divulgação da plataforma **Voxy**.

## 🚀 Como Executar Localmente

Você pode abrir o arquivo `index.html` diretamente em qualquer navegador moderno, ou rodar um servidor HTTP local:

```bash
# Na pasta /website
npm start
# ou
npx -y serve .
```

Acesse em: `http://localhost:3000`

## 🎨 Identidade Visual e Recursos

- **Design System Obsidian Mint**: Paleta dark mode premium (`#06090e`, `#0b0f17`, `#34d399`, `#863bff`, `#38bdf8`).
- **Tipografia**: Space Grotesk (títulos de impacto) e Inter (legibilidade de corpo).
- **Mockup Interativo do Voxy no Hero**: Demonstração ao vivo do visual do app com canais, chat e sala de voz simulando participantes falando em tempo real.
- **Fluxo Passo a Passo**: Apresentação clara de como criar servidor, convidar amigos e entrar nas salas.
- **Seção de Proteção Infantil & Segurança**: Destaque para conformidade com a legislação brasileira (ECA e ANPD).
- **Download**: Botão para download do instalador Windows (`.exe`) e acesso direto à versão Web.
- **100% Responsivo e Otimizado para SEO**: Meta tags Open Graph, Twitter Cards, tags semânticas e acessibilidade.
